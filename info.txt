Pasos para habilitar el servidor SSH:
Instalar OpenSSH Server: Abre PowerShell como administrador y ejecuta:
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

Alternativa gráfica: Ve a Configuración > Aplicaciones > Características opcionales > Agregar una característica > Busca Servidor OpenSSH > Instalar. 
Iniciar y configurar el servicio: En el mismo PowerShell, ejecuta:
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'

Configurar el Firewall: Asegúrate de que el puerto 22 esté abierto. Verifica o crea la regla con:
if (!(Get-NetFirewallRule -Name "OpenSSH-Server-In-TCP" -ErrorAction SilentlyContinue)) {
    New-NetFirewallRule -Name 'OpenSSH-Server-In-TCP' -DisplayName 'OpenSSH Server (sshd)' -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22
}

Una vez configurado, podrás conectarte al equipo Windows desde otros dispositivos mediante ssh usuario@IP_del_equipo

1. Activar el Escritorio Remoto (PC DESTINO)
La forma más rápida y directa en las versiones modernas de Windows (Pro, Enterprise o Server) es a través de la configuración del sistema:

Presiona Win + I para abrir Configuración.

Ve a Sistema y luego selecciona Escritorio remoto.

Cambia el interruptor de Escritorio remoto a Activado.

Confirma la acción en la ventana emergente.

⚠️ Nota: El Escritorio remoto nativo de Windows no está disponible en las ediciones Windows Home. Si el PC destino tiene una versión Home, necesitarás actualizar la licencia o recurrir a herramientas de terceros.

2. Configurar el Firewall de Windows para RDP


Vía PowerShell (Más rápido)
Si prefieres la línea de comandos, abre PowerShell como Administrador y ejecuta el siguiente comando para habilitar la regla del firewall:

PowerShell
Enable-NetFirewallRule -DisplayGroup "Escritorio remoto"
